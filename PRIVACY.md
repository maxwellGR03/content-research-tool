# Política de Privacidade

Última atualização: setembro de 2026.

Este projeto utiliza os serviços da YouTube Data API para acessar informações públicas disponíveis no YouTube.

## Dados acessados

O projeto pode acessar metadados públicos de vídeos e canais, incluindo:

- títulos
- identificadores de vídeos e canais
- datas de publicação
- duração
- visualizações
- curtidas
- comentários disponíveis publicamente

## Uso dos dados

Os dados são utilizados para pesquisa, organização e análise de conteúdo público.

O projeto não vende dados pessoais e não utiliza informações da API para publicidade direcionada.

## Autenticação

Atualmente, o sistema utiliza uma chave de API para acessar dados públicos e não solicita login de usuários do YouTube.

## Compartilhamento de dados

Os dados acessados não são vendidos nem compartilhados com anunciantes.

## Serviços do YouTube

O uso da API está sujeito aos Termos de Serviço do YouTube e às Políticas para Desenvolvedores da YouTube API.

## Contato

Para dúvidas sobre esta política, entre em contato pelo e-mail informado no pedido de acesso à API.
