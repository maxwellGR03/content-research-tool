# Política de Privacidade

Última atualização: setembro de 2026.

## 1. Sobre o projeto

Content Research Tool é uma ferramenta privada de pesquisa e análise de conteúdo público.

O projeto utiliza os serviços da YouTube Data API para localizar vídeos e canais públicos, organizar metadados e realizar análises de conteúdo e desempenho.

Atualmente, a ferramenta é executada localmente em Python e Jupyter Notebook e não está disponível para uso público.

## 2. Serviços da API do YouTube

Este projeto utiliza os Serviços de API do YouTube.

Ao utilizar informações obtidas pelos Serviços de API do YouTube, este projeto também está sujeito aos Termos de Serviço do YouTube e às Políticas para Desenvolvedores dos Serviços de API do YouTube.

Termos de Serviço do YouTube:
https://www.youtube.com/t/terms

Política de Privacidade do Google:
https://policies.google.com/privacy

Políticas para Desenvolvedores da API do YouTube:
https://developers.google.com/youtube/terms/developer-policies

## 3. Dados acessados

O projeto pode acessar informações públicas disponibilizadas pela YouTube Data API, incluindo:

- ID de vídeos;
- ID de canais;
- títulos de vídeos;
- nomes de canais;
- datas de publicação;
- duração de vídeos;
- número de visualizações;
- número de curtidas;
- número de comentários;
- outras informações públicas necessárias para pesquisa e análise.

O projeto não solicita acesso a contas privadas de usuários do YouTube.

## 4. Autenticação

Atualmente, o projeto utiliza uma chave de API para acessar dados públicos.

A ferramenta não utiliza OAuth 2.0 e não solicita que usuários façam login com uma Conta do Google ou YouTube.

## 5. Uso dos dados

Os dados obtidos são utilizados para:

- pesquisa de conteúdo público;
- organização de referências;
- análise de desempenho de vídeos e canais;
- identificação de padrões de conteúdo;
- análise de tendências;
- geração de relatórios internos.

O projeto não vende dados pessoais e não utiliza dados da API para publicidade direcionada.

## 6. Métricas derivadas

O projeto pode calcular métricas próprias para fins de análise, como médias, proporções, taxas e indicadores de desempenho.

Essas métricas são produzidas de forma independente pelo Content Research Tool e não são métricas fornecidas ou aprovadas pelo YouTube.

O uso dessas métricas está sujeito à aprovação aplicável das políticas adicionais do YouTube para métricas derivadas.

## 7. Armazenamento e retenção

Quando permitido pelas políticas aplicáveis do YouTube, estatísticas públicas, como contagens de visualizações, curtidas e comentários, e métricas derivadas podem ser armazenadas para fins de análise histórica pelo período permitido pelas políticas do YouTube.

Dados como títulos de vídeos, nomes de criadores, descrições e textos de comentários são atualizados ou excluídos conforme os requisitos aplicáveis das Políticas para Desenvolvedores da API do YouTube.

Atualmente, esses dados são armazenados localmente para fins de pesquisa interna.

## 8. Exclusão e atualização de dados

O projeto revisa e atualiza os dados obtidos pelos Serviços de API do YouTube de acordo com os requisitos das Políticas para Desenvolvedores.

Quando um dado precisar ser removido ou atualizado conforme as políticas aplicáveis, ele será excluído ou atualizado nos arquivos e bases locais utilizados pelo projeto.

Como a ferramenta atualmente não possui usuários externos nem login de usuários, ela não armazena dados privados associados a contas de usuários.

## 9. Compartilhamento de dados

Os dados obtidos através da API não são vendidos a terceiros.

O projeto não compartilha dados da API com anunciantes para fins de publicidade direcionada.

## 10. Segurança

As credenciais utilizadas para acessar a API, incluindo chaves de API, não são publicadas no repositório público do projeto.

As credenciais são armazenadas separadamente do código público.

## 11. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada para refletir alterações no projeto ou nos requisitos dos Serviços de API do YouTube.

## 12. Contato

Para dúvidas relacionadas a esta Política de Privacidade, utilize o endereço de e-mail informado no pedido de auditoria e extensão de cota da YouTube Data API.
