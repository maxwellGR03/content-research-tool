# Termos de Uso

Última atualização: setembro de 2026.

## 1. Sobre o projeto

Content Research Tool é uma ferramenta privada de pesquisa e análise de conteúdo público.

Atualmente, o projeto é utilizado localmente pelo desenvolvedor e não é oferecido como serviço público.

## 2. Uso dos Serviços de API do YouTube

Este projeto utiliza os Serviços de API do YouTube.

O uso de dados e funcionalidades fornecidos pela API está sujeito aos Termos de Serviço do YouTube:

https://www.youtube.com/t/terms

Também se aplicam as Políticas para Desenvolvedores dos Serviços de API do YouTube:

https://developers.google.com/youtube/terms/developer-policies

E a Política de Privacidade do Google:

https://policies.google.com/privacy

## 3. Finalidade

A ferramenta é utilizada para:

- pesquisa de conteúdo público;
- organização de metadados;
- análise de desempenho de vídeos e canais;
- identificação de padrões e tendências;
- criação de relatórios internos.

## 4. Limitações

O Content Research Tool não é afiliado, patrocinado ou endossado pelo YouTube ou Google.

Métricas calculadas pelo projeto, incluindo médias, taxas, proporções, classificações e indicadores próprios, são produzidas de forma independente e não representam métricas oficiais do YouTube.

## 5. Dados e conteúdo de terceiros

O acesso a metadados públicos através da YouTube Data API não concede direitos sobre vídeos, músicas, imagens ou outros conteúdos de terceiros.

O uso de conteúdo de terceiros continua sujeito às permissões, licenças e direitos aplicáveis.

## 6. Disponibilidade

A ferramenta pode ser modificada, suspensa ou descontinuada a qualquer momento durante seu desenvolvimento.

## 7. Alterações

Estes Termos poderão ser atualizados para refletir mudanças no projeto, nas funcionalidades ou nos requisitos dos Serviços de API do YouTube.

## 8. Contato

Para dúvidas relacionadas a estes Termos de Uso, utilize o endereço de e-mail informado no pedido de auditoria e extensão de cota da YouTube Data API.
