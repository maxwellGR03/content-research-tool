# Content Research Tool

Content Research Tool é um projeto pessoal de pesquisa e análise de conteúdo público.

O sistema utiliza a YouTube Data API para localizar vídeos recentes por tema e organizar metadados públicos, como:

- título
- canal
- data de publicação
- duração
- visualizações
- curtidas
- comentários

O objetivo é apoiar pesquisa de conteúdo, análise de formatos e organização de referências para criação de conteúdo.

O projeto é atualmente utilizado de forma privada e local, por meio de scripts em Python e notebooks Jupyter.

Ele não publica vídeos automaticamente, não envia spam e não modifica dados de usuários.
